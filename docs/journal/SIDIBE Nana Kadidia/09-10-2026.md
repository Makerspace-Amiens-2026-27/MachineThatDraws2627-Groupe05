# 2026-10-09 : découpe laser du boîtier

### Séance : Découverte du journal de bord et prise en main des outils de développement

**Fait :**

Pendant cette séance, j'ai commencé par suivre le tutoriel du MakerSpace Amiens sur la méthodologie de projet et la tenue d'un journal de bord. J'ai ainsi découvert comment organiser mon travail, suivre mes avancées et noter les difficultés rencontrées au cours du projet.

Ensuite, j'ai procédé à l'ouverture du projet dans **GitHub Desktop**, puis dans **Visual Studio Code (VS Code)**. Cette manipulation m'a permis d'accéder aux fichiers du projet et de préparer mon environnement de travail pour pouvoir consulter et modifier le code par la suite.

**Pourquoi :**

L'objectif était de comprendre comment assurer le suivi du projet et de me familiariser avec les outils qui seront utilisés pour son développement. J'ai également pu découvrir le lien entre GitHub Desktop, qui permet de gérer le projet et ses versions, et VS Code, qui permet de travailler directement sur les fichiers.

**Reste à faire :**

Prendre davantage en main GitHub Desktop et VS Code, explorer les différents fichiers du projet et commencer à travailler sur le code.
